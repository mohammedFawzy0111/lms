# Print several reports in one window

- STATUS: OPEN
- PRIORITY: 55
- TAGS: feature,print

"Print Selected" on the Requests page opens one window per request (openReportWindow, staggered by 300 ms). Open a single print window instead (for example /#/print?ids=a,b,c) that renders every selected report, each starting on its own page (page-break-after), with one Print button and a count. Keep the single-report route working.
